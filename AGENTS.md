# PolySparQ++ contributor guidance

- Follow the root `README.md`, `INSTALL.md`, and `CONTRIBUTING.md`.
- Keep paper mode as the default and preserve risk checks. Do not introduce real credentials or deployment-specific endpoints.
- Do not add private keys, tokens, `.env` files, database contents, trading records, or local infrastructure details to the repository.
- Preserve historical database, service, configuration, and mobile application identifiers unless a change includes a complete compatibility migration.
- Describe what changed and what checks were run in each pull request.
