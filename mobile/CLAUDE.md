# PolySparQ++ mobile client context

This directory contains the Expo / React Native companion app. The app connects to a server URL provided by the operator. Firebase push configuration is optional and must come from the developer's own Firebase project.

Do not add production endpoints, credentials, signing material, user records, or generated build output. Preserve the established app identifiers and secure-storage keys unless implementing an explicit migration.
