# Mobile client guidance

- Keep server URLs configurable and never commit private service endpoints.
- Do not commit Firebase files, signing keys, generated APKs, or local environment files.
- Preserve the existing application IDs and secure-storage keys unless a migration is planned.
- Run `npm run typecheck` for TypeScript changes and describe native build checks in the change summary.
